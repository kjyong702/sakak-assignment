# 프롬프트 개정 기록

모델은 qwen2.5:7b, 개정마다 질문 4~6개를 돌렸다. 답변 원문은 그대로 옮겼다. 최종 프롬프트 원문은 문서 끝에 있다.

시스템 프롬프트 규칙 6개: 데이터만 근거, 값과 단위 인용, 판정 준수, 주의 항목 먼저, 관련 항목만, 존댓말 3~5문장.

## v2 변경

- 검진일을 먼저 말하게 했다 (안내서 예시 답변의 첫 문장이 검진일이다)
- "언급하는 항목마다 값과 단위 인용"으로 규칙을 좁혔다. v1의 "수치를 말할 때는"은 수치를 아예 안 말하는 길을 열어 두었다
- 정상(B)의 뜻을 프롬프트에 박았다: 경계 범위, 약간 높거나 낮은 편
- 판정 없음/보류 항목은 그 항목을 직접 물을 때만 언급하고 전체 요약에서는 빼게 했다
- 전체 요약의 순서를 정했다: 검진일 -> 주의 항목(값 포함) -> 주요 항목이 정상임을 값과 함께 짧게
- 답변 형식 예시를 자리표시자로 넣었다. 실제 수치를 예시에 넣으면 다른 환자 질문에도 그 수치를 베낄 위험이 있다

## v2.1 변경 (코드)

- 전체 요약(항목 미선택) 컨텍스트에는 판정된 항목만 넣고, 판정 안 된 항목은 각주 한 줄("판정하지 않은 항목: 키, 몸무게, 허리둘레, 시력, 청력")로만 알린다. 그 항목을 직접 물으면 성별별 판정까지 그대로 보여 준다
- 판정별 표현을 규칙으로 정했다: 정상(B)는 "약간 높은(낮은) 편", 질환의심은 "진료 상담이 필요한 수치"

## v3 변경

- **검증 노드에 항목 검사를 추가했다 (코드).** 답변이 언급한 검진 항목이 이 질문의 컨텍스트에 없는 항목이면 재생성한다.
  혈압 질문에 콜레스테롤 이야기를 붙이는 유형을 잡기 위한 것이다. 키워드가 여러 항목에 걸치는 경우(콜레스테롤은 총/HDL/LDL)는
  그중 하나라도 컨텍스트에 있으면 통과시킨다
- 재생성 프롬프트를 수치와 항목 모두에 쓰도록 일반화했다
- 보류 항목 규칙에 "판정 없음은 괜찮다는 뜻이 아니라 판정을 못 한 것"을 명시하고, 주의 항목이 없을 때의 마무리 문장을 정했다

적혀 있는데도 생기므로 **검증 노드에 판정 일치 검사를 추가했다** (v3.3, 코드). 답변에서 항목 이름 뒤에 붙은
판정 말을 찾아 컨텍스트의 판정과 비교하고, 다르면 "판정 불일치: 공복혈당: 답변 정상(B), 데이터 정상(A)"를
사유로 한 번 재생성한다. 이후 프롬프트는 고정하고 모델 비교로 넘어간다.

## v3.4 변경 (코드, 터미널 화면 캡처에서 발견)

터미널 대화 화면을 캡처하다가 검증을 통과한 오답을 두 개 봤다 (`docs/screenshots/chat-terminal-before-v3.4.png`).
혈압 125/82(정상(B))가 "혈압, BMI, 공복혈당 등은 모두 정상(A)입니다"에 묶였고, 공복혈당 95(정상(A))가
"약간 높은 편"으로 나왔다. 판정 일치 검사를 두 방향으로 넓혔다.

- 판정 이름 없이 "약간 높은(낮은) 편", "진료 상담이 필요한 수치"만 쓴 문장은 그 표현을 판정으로 되읽는다
  (프롬프트가 그 표현을 정해 두었으므로 역으로 읽을 수 있다)
- 항목을 나열하고 판정을 하나 붙인 문장은 그 판정을 나열된 항목 전부에 적용한다. "제외" 같은 말이 있거나
  판정이 섞인 문장은 공통 판정을 쓰지 않는다

## v3.5 변경 (코드, 제출 전 검토에서 발견)

제출 전에 평가 기준별로 코드를 다시 검토했고 확인된 문제를 고쳤다.

- 이전 검진을 포함하면 같은 항목의 판정이 두 줄이 되는데 검사가 마지막 줄만 남겨 최근 판정을 이전 판정으로
  덮어썼다. 정답도 판정 불일치로 재생성되고 미통과로 끝났다. 항목별 판정을 집합으로 두고 둘 중 하나와 맞으면 통과
- 참고치 인용("정상(A) 120미만")을 판정 말로 읽던 것을, 뒤에 숫자가 오면 인용으로 본다
- 생활 습관 권고 단어(체중, 비만, 복부)를 무관 항목으로 오탐하던 것을 제외했다
- 질문에 나온 숫자("130 넘나요?")를 답변이 되풀이하면 환각으로 잡던 것을 허용했다
- "간단히"가 간 수치 질문으로, "신장 기능"이 키 질문으로 잡히던 키워드 규칙을 고쳤다. "비교", "변화"만으로
  이전 검진 비교로 읽던 감지도 시점 표현 위주로 바꿨다
- 참고치 사이 값(LDL 148)이 사유 없는 판정 없음으로 나가고 규칙이 그것을 성별 문제로 설명하게 하던 것을
  "참고 범위 사이의 값" 사유와 "괄호 안의 이유를 그대로 말한다" 규칙으로 바꿨다

## v3.6 변경 (코드, 요약 컨텍스트를 블록으로)

v3.5 뒤에도 환자 1의 전체 요약에서 qwen이 혈압(정상(B))을 "혈압, BMI, 공복혈당 등은 모두 정상(A)"로 묶는 일이
이어졌다. 검증이 잡아 재생성해도 같은 답이 나와 `verified: false`로 끝나는 비율이 높았다. 규칙 5("정상(B)와
질환의심 항목을 값과 함께 먼저")는 이미 있었으므로 규칙을 더 쓰는 대신 컨텍스트 구조를 바꿨다. 요약 컨텍스트를
`[주의 항목: 정상(B)나 질환의심. 먼저 말할 것]`과 `[정상(A) 항목]` 두 블록으로 나눠 묶을 대상을 물리적으로
떼어 놓았다.

결과: 같은 질문 3회 모두 1회 시도에 통과. "혈압 125/82 mmHg는 정상(B) 범위에 속하며 약간 높은 편입니다. (정상
항목 나열) 다만 혈압이 약간 높은 편이므로 생활 습관에 주의를 기울이는 것이 좋겠습니다." 응답 15~19초
(v3.5는 재생성 포함 40~50초).

교훈: 7b 모델에게는 "무엇을 먼저 말하라"는 지시보다 "먼저 말할 것을 먼저 보여 주는" 입력 구조가 잘 듣는다.

## v3.7 변경 (코드, 언어 가드)

최종 비교에서 qwen이 간 수치 답변 끝에 중국어를 섞었다 ("김영희女士, 请告知我您的性别..."). 수치, 항목, 판정
검사는 전부 통과했으므로 `verified: true`로 나갔다. 한자가 하나라도 있거나 한글이 글자의 절반 미만이면 걸리는
언어 검사를 검증 노드에 추가했다. qwen 계열의 알려진 언어 전환 문제라 프롬프트로 막기보다 검사가 확실하다.

## 최종 프롬프트 원문

시스템 프롬프트 (`app/services/prompts.py`의 `SYSTEM_PROMPT`):

```
당신은 건강검진 결과를 설명하는 상담 도우미입니다. 아래 규칙을 지키세요.

1. 제공된 검진 데이터만 근거로 답합니다. 데이터에 없는 항목이나 수치는 말하지 않습니다.
2. 언급하는 항목마다 데이터의 값과 단위를 그대로 인용합니다. 항목 이름도 데이터의 이름을 씁니다.
3. 판정은 각 항목에 붙은 판정 결과를 그대로 따르고 범위를 다시 계산하지 않습니다. 정상(A)는 정상, 정상(B)는 경계 범위(약간 높거나 낮은 편), 질환의심은 진료 상담이 필요한 상태입니다.
4. 판정 없음은 괜찮다는 뜻이 아니라 판정을 못 한 것입니다. 괄호 안의 이유를 그대로 말합니다. 성별에 따라 다르다고 적힌 항목만 성별 정보가 필요하다고 말하고 성별별 판정을 알려 줍니다.
5. 전체 결과를 물으면 검진일을 먼저 말하고, 정상(B)와 질환의심 항목을 값과 함께 먼저 말한 뒤, 정상인 항목은 '[항목] [값 단위], [항목] [값 단위]는 정상입니다'처럼 한 문장으로 묶습니다. 정상 항목 사이에 '다만'이나 '이지만'을 쓰지 않습니다.
6. 진단을 내리지 않습니다. 경계나 질환의심 항목에는 생활 습관 권고와 전문의 상담을 권합니다.
7. 한국어 존댓말로 3~5문장으로 답합니다.
8. 정상(B)는 '약간 높은(낮은) 편'으로, 질환의심은 '진료 상담이 필요한 수치'로 표현합니다.
9. 정상(A) 항목에는 주의나 권고를 붙이지 않습니다. 주의 항목이 하나뿐이면 그것만 말하고 나머지는 정상으로 묶습니다.
```

사용자 프롬프트는 `[검진 데이터]` 컨텍스트, `[질문]`, `[답변]` 순서이고 재생성할 때는 앞에 이 문장이 붙는다:

```
이전 답변에 문제가 있었습니다 ({reason}). 제공된 데이터에 있는 항목과 수치만 사용해 다시 답하세요.
```

컨텍스트 예 (환자 1, 혈압 질문):

```
환자 이름: 홍길동

[최근 검진] 검진일 2025-08-15 (서울병원)
종합 소견: 전체적으로 정상 범위 내 건강 상태입니다.
- 혈압: 125/82 mmHg -> 정상(B) (참고치: 정상(A) 120미만 이며/80미만 / 정상(B) 120-139 또는 /80-89 / 질환의심 140이상 또는 /90이상)

판정 기준: 정상(A)는 정상, 정상(B)는 경계 범위라 생활 습관 주의, 질환의심은 진료 상담 필요. 판정은 참고치 표로 계산한 결과입니다.
```
